# First Response Plan

Read the task and the tool instructions first.

Then respond with:
- the objective in one sentence
- the exact user-visible task goal
- a concrete ordered tool sequence
- the next interactable you expect to use first, with element type and ref if visible
- a warning check for whether that ref could be a misleading text label or weakly described button
- the specific input you will give the first tool
- what you expect to learn or confirm from that first tool result
- the next 1 to 3 tool steps after that, in order
- the concrete success condition for the task

Keep it short, but make it actionable and specific.
Do not stay at a generic summary level.
Name the page, element, query, or target type you expect to use when you can.
