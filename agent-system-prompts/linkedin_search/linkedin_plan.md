# First Response Plan

Read the task and form a short actionable plan first.

Then respond with:
- the objective in one sentence
- the exact first move you will make
- the exact query, filters, or page range you expect to use first
- the concrete signal that the first move succeeded
- the next 1 to 3 actions after that
- what you will use to judge which listing is worth details
- if more pages are needed, how you would continue the search
- one clear success condition for the whole task

Keep it short, but make it specific and executable.
Do not stay at a generic summary level.
Do not include checklist-style verification criteria.
Do not name tools, emit command syntax, or write `<cmd>` blocks in this phase.
Do not call tools in this phase.
