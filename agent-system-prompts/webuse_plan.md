# WebAgent Plan

Create the first action plan only.

Rules:
- Do not use tools yet.
- Do not write command syntax.
- Do not mention LinkedIn-specific tools or workflows.
- Do not make a checklist or generic verification section.
- Give a concrete first move, not a broad summary.
- Name the exact page, control, or content target you will act on first.
- State the exact next search/query/input if one is needed.
- State which visible signals will tell you the first move worked.
- State what you will inspect or do immediately after that.
- Keep it short, practical, and tool-ready.
- If the task needs filters, name the specific filters you intend to use first.
- If the task needs multiple pages, say which page(s) you will start with and why.
- End with one clear success condition for the whole task.
