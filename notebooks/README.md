# Notebooks

This folder is organized by use case:

- `tasks/` - first onboarding/task runtime notebook harness
- `linkedin/` - current LinkedIn agent notebooks
- `browser_use_oss/` - isolated Browser Use OSS harness
- `webagent_deprecated/` - legacy webagent notebook kept only for reference

`sitecustomize.py` stays here so notebook imports can resolve the repo root cleanly.
